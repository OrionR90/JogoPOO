# 🦖 Cadillacs and Dinosaurs – Projeto Java

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um jogo inspirado no clássico jogo de fliperama **Cadillacs and Dinosaurs**, lançado originalmente nos anos 90.

O jogo está sendo desenvolvido como trabalho acadêmico para a disciplina de **Programação Orientada a Objetos (POO)**, utilizando a linguagem Java e a biblioteca Swing para a construção da interface gráfica.

O objetivo é recriar alguns dos elementos característicos do jogo original, proporcionando uma experiência de gameplay inspirada nos clássicos jogos de arcade, enquanto aplicamos na prática os conceitos estudados durante a disciplina.

## 🎮 Inspiração

O projeto tem como principal referência o jogo [Cadillacs and Dinosaurs](https://en.wikipedia.org/wiki/Cadillacs_and_Dinosaurs_(video_game)), conhecido por sua jogabilidade no estilo Beat'em up, combates contra inimigos e ambientação em um mundo habitado por humanos e dinossauros.

## 🛠️ Tecnologias utilizadas

- **Java** – Linguagem de programação utilizada no desenvolvimento.
- **Java Swing** – Biblioteca utilizada para a criação da interface gráfica.
- **Programação Orientada a Objetos** – Aplicação de conceitos como:
  - Classes e objetos;
  - Encapsulamento;
  - Herança;
  - Polimorfismo;
  - Abstração.

## 🚀 Funcionalidades

As funcionalidades do jogo serão desenvolvidas ao longo do projeto, podendo incluir:

- Movimentação do personagem;
- Sistema de combate;
- Inimigos e obstáculos;
- Sistema de pontuação;
- Interface gráfica interativa;
- Progressão entre fases.

## 📂 Estrutura do projeto

A organização do código seguirá a estrutura de um projeto Java, separando as classes de acordo com suas responsabilidades.

```text
src/
 ├── model/
 ├── view/
 ├── controller/
 └── Main.java
```

*Obs.: A estrutura poderá ser modificada conforme a evolução do desenvolvimento.*

## ▶️ Como executar

1. Clone este repositório:

   ```bash
   git clone https://github.com/OrionR90/JogoPOO.git
   ```

2. Abra o projeto em uma IDE compatível com Java, como Eclipse ou IntelliJ IDEA.

3. Verifique se o JDK está instalado e configurado.

4. Execute a classe principal (`Main.java`).

## 🎓 Objetivo acadêmico

Este projeto tem como finalidade consolidar os conhecimentos adquiridos na disciplina de Programação Orientada a Objetos, utilizando Java para desenvolver um jogo com interface gráfica e explorar a organização de um software por meio de classes, objetos e suas interações.
